# Loan Default Risk Dashboard | Power BI + SQL

## Project Overview

The **Loan Default Risk Dashboard** is a business intelligence project designed to explore loan portfolio performance, identify patterns in historical defaults, and analyze borrower and loan characteristics using SQL and Microsoft Power BI.

The report organizes key portfolio metrics and risk indicators into three pages: Executive Risk Overview, Customer Risk Segmentation, and Credit Review Queue.

## Dashboard Pages

### 1. Executive Risk Overview

Provides a high-level view of the loan portfolio through KPI cards, charts, and interactive filters.

**Key indicators include:**
- Total loans
- Total loan amount
- Defaulted loans
- Default rate
- Average FICO score
- Average debt-to-income (DTI) ratio

**Visualizations include:**
- Default rate by loan grade
- Default rate by FICO band
- Default rate by loan purpose
- Default rate trend by issue year
- Loan amount versus default rate by grade

### 2. Customer Risk Segmentation

Explores how historical default rates vary across borrower and loan segments.

**Analysis includes:**
- FICO and DTI risk-band comparisons
- Default rate by income band
- Loan purpose risk analysis
- Grade and sub-grade risk heatmap

### 3. Credit Review Queue

Displays loan-level information to support closer examination of individual records.

**Fields shown include:**
- Loan ID
- Loan amount
- FICO score
- Debt-to-income ratio
- Loan grade
- Interest rate
- Annual income
- Loan purpose

## How to Explore the Project

1. Clone or download this repository.
2. Open the Power BI `.pbix` file in Microsoft Power BI Desktop, if included.
3. Connect or update the data source if required.
4. Review the three report pages and explore the available filters.

**Note:** The Power BI file, SQL scripts, and source data should be included in the repository only if they are available and appropriate to share.

## Important Limitations

This project is intended for historical portfolio analysis and visualization. Risk segments and observed default rates are descriptive indicators, not proof of causation or a guarantee of future borrower behavior.

The dashboard does not, by itself, constitute a validated default-prediction model or a production-ready credit decision system. Metrics depend on the source data, the definition of a default, and the calculations used in the report.
